# Truth Collective image placeholders

Dimension-labeled placeholders for Media Replace.

## Locked sizes

| Use | Size | File |
|-----|------|------|
| Hub / hero / category / path tile | **1600 × 1000** | `tc-placeholder-hero-tile-1600x1000.png` |
| Product card | **1200 × 750** | `tc-placeholder-product-card-1200x750.png` |
| Square product / book cover | **1000 × 1000** | `tc-placeholder-product-square-1000x1000.png` |
| Portrait / editorial | **800 × 1000** | `tc-placeholder-portrait-800x1000.png` |
| Open Graph / social | **1200 × 630** | `tc-placeholder-og-1200x630.png` |

Each PNG shows the exact pixel size in gold on a navy panel: **REPLACE THIS IMAGE**.

## Also

- Per-slot Computers labels: `tc-placeholder-computers-*-1600x1000.png`
- Tech child heroes: `tc-placeholder-*-hero-1600x1000.png`
- SVG data-URI helper for scaffolds: `diagnostics/scaffolds/tc_placeholders.py`

## Workflow

1. Upload the matching placeholder (or your final art at that size) to Media Library.
2. On the page, Media Replace the placeholder slot.
3. Do not leave SVG data-URI placeholders for Semrush final if Rank Math flags them; prefer real Media Library PNG/JPG.
