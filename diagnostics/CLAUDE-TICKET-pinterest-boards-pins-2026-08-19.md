Build a Pinterest system that attracts loyal followers for Truth Collective (decision certainty, calm authority). Boards + pin titles/descriptions ready for Daniel to create in Pinterest.

## Voice locks
No em dashes, no contractions, no hype, no clickbait, no fake urgency. Affiliate-honest. Staging URLs OK for now; note LIVE_URL_LATER where launch domain will replace.

For each board: name, 1-sentence purpose, 5 example pin themes, which TC hub it supports (Technology, Smart Lighting, Office, Books, Self-Help, Productivity, Ones Who Gave, Truth Untold, AI Podcast, Selection Standards).

## Deliverable B — 30 pin briefs
For each pin:
- Board name
- Pin title (≤100 chars)
- Description (2–4 sentences + soft CTA)
- Alt text
- Source page idea (hub or child already rebuilt on staging)
- Image brief for Canva (aspect 2:3, what to show, text overlay max 6 words)

## Deliverable C — First-week posting order
Day 1–7: which pins, which boards, why that order builds a coherent profile.

## Forbidden
Inventing product grades, medical claims, “guaranteed results,” site code.
