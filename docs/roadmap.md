# Truth Collective — Roadmap to Launch and Growth

The plan is built to reduce Daniel's load. BDM does the thinking, audits, code,
and copy. Daniel executes in focused batches. No guesswork, no page-by-page
reinvention.

## The efficiency principles (the how)

1. Template first, not page by page. Fix a pattern once, then clone it across the
   whole group. Never hand-edit twelve pages when one template fix covers them.
2. Batch execution. Daniel works one group per session, not scattered pages.
3. Punch lists, not guesswork. BDM returns an exact, ordered list per page.
4. One decision at a time. BDM surfaces only the decisions that truly need Daniel,
   ranked, and defaults the rest.
5. Systemic before cosmetic. Crawl fixes and templates before per-page polish.
6. Launch blockers must be perfect. Nice-to-haves ship after launch.
7. Protect the finished pages. Build a URL map before any reparenting.

## Phase 0 — Systemic unblock (done once, helps all 85 pages)

- Lock one hub tile template and one card system site-wide.
- Fix the AI hub canonical that points to a 404. Make hubs self-canonical.
- Fix the reusable newsletter block that carries an em dash. One fix, site-wide.
- Confirm the schema templates for parent, child, sub-child.

## Phase 1 — Template-group pipeline

Group the pages by shared template and process each group as a unit. Order by ROI
and speed to monetization:

1. The three money pages: Best Standing Desks, Best Office Chairs Under 500,
   Best Monitors for Productivity.
2. Recommended Books hub and its 12 category children (most templated).
3. Office Workspace hub and children.
4. Technology hub and children.
5. Smart Lighting, Productivity Tools.
6. Self-Help monetized pages, then the non-monetized help pages, held to the same
   trust and technical standard.
7. The Truth Untold editorial series.

Per page: BDM audits from staging, returns the punch list, Daniel applies it in a
batch, BDM verifies against staging.

## Phase 2 — Pre-launch gate

- Run the Publish Gate from the Master Brief on each page.
- Confirm the launch blockers in `launch-checklist.md` are green.
- Complete the internal link map, up, down, sideways.
- Run one consistent schema pass across all pages.
- Then run SEMrush or an equal audit. Fix only proven issues.

## Phase 3 — Migrate to live

- Build the URL and redirect map for old live URLs.
- Flip robots to allow crawling and uncheck Discourage search engines in
  WordPress Reading. Staging currently blocks all crawling, which is correct for
  staging but must not carry to live.
- Make every hub and page self-canonical.
- Submit the sitemap in Google Search Console and request indexing on the money
  pages first.
- Confirm no staging URLs, no noindex, and no dead EXPLORE links remain.

## Phase 4 — Grow (after launch, in parallel with AI help)

- Repurpose finished pages and the Truth Untold series into scheduled posts.
- Pinterest pins from three to five Canva templates, scheduled with the chosen tool.
- LinkedIn as the primary editorial channel.
- BDM drafts pin titles, descriptions, and post copy in batches, in brand voice.
- Start from zero followers with consistency, not volume. Quality pins to
  monetized, indexed pages only.
